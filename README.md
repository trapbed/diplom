Платформа онлайн-курсов с контролем знаний

Группы пользователей образовательной платформы:
- студент;
- администратор;
-  автор.
Функциональные возможности студента:
- авторизация;
- управление профилем;
- просмотр каталога курсов с учетом фильтрации, сортировки и поиска;
- просмотр подробной информации о курсе;
- запись на курс;
- прохождение курса;
- прохождение тестирования в рамках курса;
- просмотр прогресса по курсам и урокам;
- просмотр статистики по прохождению тестирований;
- просмотр результатов тестирования;
- оценка пройденного курса;
- просмотр всех отзывов;
- получение сертификата о прохождении курса с возможностью сохранения.
Функциональные возможности автора курсов:
- авторизация;
- управление профилем;
- просмотр своих курсов с учетом фильтрации, поиска и сортировки;
- управление своими курсами;
- управление контентом курсов (уроки и тесты);
- управление каталогом изображений;
- просмотр статистки прохождения тестирований;
- просмотр своих заявок на отображение курсов в каталоге с учетом статуса;
- отправка заявки на отображение курсов в каталоге.
Функциональные возможности администратора:
- авторизация;
- управление профилем;
- просмотр информации о пользователях;
- управление доступом пользователей;
- управление заявками на авторизацию в роли автора;
- управление категориями курсов;
- управление заявками на отображение курсов в каталоге;
- управление доступом курсов;
- просмотр статистики по пройденным тестам.
Ограничения в информационной системе:
- на одну почту можно зарегистрировать только один аккаунт;
- записаться на курс может только авторизованный пользователь.
